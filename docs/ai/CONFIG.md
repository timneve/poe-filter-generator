# config.toml map (PoE1)

Key -> effect -> code reader. Full comments live in `config.toml`; grep the key there before editing.
Tier-name values accept: `top high mid minor low brown dust` + often `variable`, `unknown`, `hide`.
`league_start = true` overrides many keys at load (`apply_league_start` = `league_start_values` written into cfg; `build_text` applies it to a copy when not yet applied), noted as LS. `tools/league_start.py start` writes the SAME values into config.toml / modules.toml (backup, `status`, `restore`): a key `league_start_values` sets must exist in the file.

## Top level

| Key | Effect | Reader |
|---|---|---|
| `tiers.<name> = <div fraction>` | thresholds x live divine price, no chaos floor; `dust = 0` (everything below brown). No divine price -> `FALLBACK_DIVINE` | `split_tiers`, `exchange_divine`, `apply_divine_tiers`, `Tiers` |
| `variable_after` | tier that blue "variable" ranks right after (default minor -> top, high, mid, minor, variable, low, brown, dust) | `Tiers.order` / `Tiers.rank` |
| `hide_tiers` | priced but hidden (LS: none) | `hidden` |
| `quiet_tiers` | `[style.quiet]` look, keep font size | `style_for` |
| `jackpot_divine` | never hide items >= this; groups -> variable | `jackpot_chaos` |
| `league`, `output_name`, `output_dirs`, `cache_minutes` | IO | `detect_league`, `main`, `fetch_all` |
| `hide_forbidden_tome` | true: hide it regardless; false: shown, module maps `exoticmap->sanctum.*` Hides skipped (`MAP_ITEM_CONFIG_OVERRIDES`) | `emit_visibility_toggles`, `emit_special_maps` |
| `show_contracts` | false: hide every Heist contract (any rarity) regardless; true: all shown, module maps `heist->contract.handpicked` Hide skipped (`MAP_ITEM_CONFIG_OVERRIDES`) | `emit_visibility_toggles`, `emit_special_maps` |
| `show_5_links`, `show_6_links`, `show_mirrored` | toggle `# BEGIN/END` sections in `rules/top.filter` (off: `TOGGLE_OFF` text or nothing). `show_6_links` also stands for module `misc` `6l.*` ([0100], string value, never emitted: top's 6L Show is a superset) | `hand_rules` |
| `show_gold` | false: all gold hidden. true: `gold_min_stack` decides in maps, campaign gold shown small (LS true) | `emit_gold` |
| `show_small_gold` | with `show_gold`: stacks below `gold_min_stack` also shown in maps, small look (no `gold.anyother` Hide; LS true) | `emit_gold` |
| `gold_min_stack` | with `show_gold`: maps (area 68+) stacks >= N shown (module `misc` gold.stack3 look), smaller hidden; module `misc` gold.* keys are string values following it (one source of truth, not `[misc] enabled`); <= 1 or `show_small_gold`: no gold Hide | `emit_gold` |
| `always_top_classes` | item classes always top tier (tink), first block, priced or not, beats `[overrides]` / modules (default `["Vault Keys"]` = Reliquary keys; module `maps` relickeys* follow it) | `emit_pinned_stackables` |
| `league_start` | show almost everything: `apply_league_start` sets `league_start_values` (config keys incl. show_* / hide_forbidden_tome / `[rares]` base tiers all + min_ilvl 68 / `[maps] corrupted_min_tier` 0 / every `enabled` of `LS_ENABLE_TABLES`, `[vendor_recipes.*]`, `[content.*]` / `[overquality]` / `[exchange.unpriced_tiers]` hides; every off module Show on except `LS_KEEP_SECTIONS`: rares [[2600]], jewels [2805], crafting [2302]; every on module Hide off except `LS_KEEP_HIDES`: maps [3302], leveling); no emitter reads the flag (only the header). Same values as `tools/league_start.py start` | `apply_league_start`, `league_start_values`, `build_text` |
| `colors.*` | palette: the only colour values. Styles / rules / code / `*_color` keys use names; other colours (NeverSink copies) snap to nearest | `apply_palette`, `report.tier_strip` |
| `gear_text_color`, `campaign_white_text_color` | gear text colour (`[colors]` name) | `emit_defaults` |
| `unknown_as_variable` | base with any unpriced wiki unique -> blue | `price_unique_bases` |

| `[vendor_recipes.<name>]` | `enabled`, `tier` (price tier name or `variable`, floor by `Tiers.rank`; other -> ValueError), `class` (str or list), `bases` (any rarity, uniques floored per base) or `conds` (raw conditions, all required, any base) + optional `rarity` list, optional `any` (raw filter conditions, one block each; left out = any state), optional `sizes` (`RECIPE_SIZES` names small / medium / large = FilterBlade RGB Width/Height sets, one block set each; [] = any; unknown -> ValueError) + `area_level` ([min, max] AreaLevel; [] = any) - written out in `chromatic`, `note` (report text). ## Other data files

- `fallback_tiers.toml`: `[currency]` name -> NeverSink tier number ("1".."9"), `[cards]` name -> NeverSink card group ("t1".."t5"); every known name. Made by `tools/import_fallback_tiers.py`, loaded into `cfg["fallback_tiers"]`, mapped by `[exchange.reference_*_tiers]`.
- `unique_tiers.toml`: top-level keys `0 = [names]` .. `5 = [names]` (0 = rarest). Hand-copied from poewiki. Loaded into `cfg["unique_tiers"]`.
- `config_poe2.toml`: colours = `config.toml` `colors.*` (own `[colors]` table would replace it; `load_cfg`), `league`, `output_*`, `cache_minutes`, `reference` (NeverSink export appended; `reference_body`, `reference_basetypes`), `hide_tiers`, `quiet_tiers` (`Tiers`), `show_gold` (`GOLD_HIDE` in `build_text`), `[tiers]` (div fractions, `dust = 0`, `Tiers`), `[exchange] types` (`fetch_all`), `min_volume/min_units/trusted_volume` (`reliable`), `max_stack` (`build_text`).
